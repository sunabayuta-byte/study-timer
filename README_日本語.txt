STUDY TIMER 試作品 v1

これはChromeで使うPWA形式の試作品です。
ストップウォッチ、今日の累計、全期間累計を備えています。
計測状態と累計はブラウザのローカルストレージに保存されます。

重要：
・ホーム画面に追加できるアプリ形式ですが、Androidのネイティブウィジェットではありません。
・PWAとしてインストールするには、HTTPS対応のWebサーバーに配置する必要があります。
・データはこの端末・このブラウザ内に保存されます。ブラウザデータを消去すると消える場合があります。
・画面を閉じている間の時間は開始時刻から計算します。

次の段階：
Androidネイティブアプリと本物のホーム画面ウィジェットを作るには、Kotlin/Android開発環境で別途実装します。
